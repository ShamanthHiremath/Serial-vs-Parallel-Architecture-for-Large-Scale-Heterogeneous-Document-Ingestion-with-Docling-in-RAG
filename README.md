# Serial-vs-Parallel-Architecture-for-Large-Scale-Heterogeneous-Document-Ingestion-with-Docling-in-RAG
Compare serial vs parallel document ingestion with Docling in RAG pipelines. Parses mixed corpora (PDF/DOCX/PPTX/images), uses GPU for OCR, embeddings, FAISS indexing. Tracks latency, throughput, and resource usage. Research-ready, easy to run, CSV output for analysis.
